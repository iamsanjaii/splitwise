
# 💸 SplitWise Clone – Expense Tracker App

A simple and intuitive expense tracking app built with **React Native** using **Expo**. Inspired by Splitwise, this app allows you to manage group expenses and track shared spending with friends.

---

## 🚀 Features

- 👥 Create Groups to manage expenses
- 📊 View all activities in a centralized Activity screen
- 👤 Manage your profile in the Account section
- 📈 Dynamic visualizations like pie charts for splitting
- 💾 Data persistence using `AsyncStorage`
- 🔒 Logout and session management

---

## 📱 Screens

- `Groups`: Create & view group expenses
- `Activity`: Overview of all recent transactions
- `Friends`: Manage your friends list *(coming soon)*
- `Account`: Profile, preferences, and logout

---

## 🛠️ Built With

- **React Native**
- **Expo**
- **AsyncStorage**
- **React Navigation**
- **Feather Icons**
